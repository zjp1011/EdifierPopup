# 漫步者连接弹窗 EdifierPopup

蓝牙连上漫步者耳机后，自动在屏幕上弹出动画卡片。内置 5 种样式：
经典卡片 / 灵动岛 / 霓虹光环 / 声波律动 / 星空爆发。

## 工作原理
通过清单里静态注册的「蓝牙设备已连接」广播触发，不需要常驻后台服务。
App 即使被划掉，只要没被「强行停止」，耳机连上时系统会唤醒它并弹出悬浮窗。

## 打包
把整个项目上传到 GitHub 仓库（main 分支），Actions → Build APK 自动打包，
在运行记录底部 Artifacts 下载 APK。

## 首次使用（vivo）
1. 打开 App，点 1、2、3 授权蓝牙、悬浮窗，并在应用详情里放行
   「后台弹出界面」「自启动」，电池设为后台不限制
2. 选一个弹窗样式（点一下立即预览）
3. 设备名关键词默认 EDIFIER,漫步者；如果你的耳机名字不含这些词，改成实际名字，或留空
4. 回桌面，关掉耳机再连一次测试

## 注意
- 只显示总电量（系统隐藏接口），部分机型读不到会显示 --
- 不要在应用详情里点「强行停止」
